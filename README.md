A one-line fortune cookie message an AI agent would crack open, entered in the
[Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e)
competition on [make.fun](https://make.fun).

> You will meet a tall, dark stranger: your context window, and it is already full.

`main.py` (pure Python standard library) writes the fortune to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, byte-identical on every run.
